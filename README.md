# bg-pos-aio-release
BiG AIO 正式包发布仓库

## 公开发布说明约束

发布说明只保留用户可感知的功能、修复、已知限制及必要升级注意事项。可以保留版本号、构建号、安装包文件名、公开下载链接、大小和安装包校验值；安装包校验值不属于源码提交 ID。

禁止包含：

- 业务服务器域名、IP、端口、内网地址、连接串、账号密码、Token 和密钥。
- 私有源码仓库链接及源码提交 ID。
- CI 运行编号、runner 状态、构建机磁盘占用、测试失败日志和内部排障细节。

内部验证记录应保存在私有开发记录中，不能把未验收改写为已通过。AIO 发布工作流在构建前及上传前校验公开说明；轻量标签使用安全的默认文案，不读取所指提交的内部说明。手工编辑历史 Release 正文时也必须遵循相同约束并完成校验与人工复核。
